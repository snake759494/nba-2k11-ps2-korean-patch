# NBA 2K11 한글화 번역 지침

- 파일: `translation/ko/<묶음>.json` = `{ "id": "번역" }` (원문 묶음은 `translation/en/<묶음>.json`). 빠진 id 는 영문 유지.
- 제어 코드는 그대로 둔다: `|CROSS|`, `|M_BACK|`, `|REG|` 등 `|...|` 태그, `ð`(강조 토글), `%s %d %c %%`, `{0}`, `{0:D2}`, `\n`, `[1]` 등.
- 고유명사(선수·코치 이름, 팀 별칭 Lakers 등, 경기장, 브랜드/상품명, 곡·아티스트)는 영문 유지. 단 일반명사가 붙은 경우 일반명사만 번역 (예: `Celtics Cap` → `Celtics 모자`).
- 표기: 리바운드, 어시스트, 스틸, 블록, 턴오버, 야투, 3점슛, 자유투, 덩크, 레이업, 픽앤롤, 포스트, 아이솔레이션, 트레이드, 드래프트, 샐러리 캡, 프리 에이전트(FA), 시즌, 플레이오프, 파이널.
- 포지션 약어(PG, SG, SF, PF, C)는 영문 유지. 통계 약어는 칸이 좁으므로 1~3자 한국어 또는 원문 유지
  (PTS 득점, REB 리바, AST 어시, STL 스틸, BLK 블록, TO 실책, FG% 야투%, 3P% 3점%, FT% 자유투%, MIN 시간, W 승, L 패).
- 메뉴 항목은 명사형, 안내문은 '~하세요/~합니다' 존댓말.
- 디버그·내부 문자열(Test, DEBUG 등)은 번역하지 않음.
